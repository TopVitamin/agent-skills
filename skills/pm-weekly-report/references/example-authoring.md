# 脱敏与虚拟案例制作

仅用户要求脱敏、改编或制作案例时使用，不是正常周报成稿流程。

保留工作类型、动作、状态及依赖关系；真实名称改为功能性称呼，并处理精确日期、地点、金额、版本、独特算法及多个细节组合的识别风险。不在分发材料中存放原文或名称对应表。

普通脱敏不意味着允许新增事实。用户明确授权虚拟创作时，可设置数量、比例、时间及对应进展细节，标注为“基于历史材料改编的虚拟示例”。分子分母、本周与累计、已修复与已验证、正文与计划必须对应一致。该授权只适用于案例。

完整示例正文放在 markdown 代码块，作者说明、案例背景留在外面。虚拟身份标识在代码块内保留，保证独立复制后仍有说明；它不是正式周报的固定格式。
